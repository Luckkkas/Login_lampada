💡 Lamp Login — Animated Login Form

Uma interface de login interativa e moderna, desenvolvida com HTML, CSS e JavaScript, apresentando uma lâmpada animada que proporciona uma experiência visual diferenciada.

O projeto combina um formulário com efeito glassmorphism, iluminação dinâmica e elementos animados, criando uma interface elegante e imersiva.

✨ Preview

«💡 Uma experiência de login onde a iluminação faz parte da interação com a interface.»

🚀 Tecnologias utilizadas

- HTML5 — Estrutura e organização dos elementos.
- CSS3 — Estilização, animações, efeitos visuais e responsividade.
- JavaScript — Interatividade e manipulação dos elementos da página.
- Google Fonts (Outfit) — Tipografia da interface.

🎨 Funcionalidades e recursos visuais

- 💡 Lâmpada com efeito de iluminação.
- 🌙 Ambiente com iluminação dinâmica.
- ✨ Vagalumes animados.
- 🪟 Formulário com efeito Glassmorphism.
- 🔐 Campos de usuário, e-mail e senha.
- 🔗 Botões de acesso com Google e GitHub.
- 🎨 Interface moderna com elementos interativos.
